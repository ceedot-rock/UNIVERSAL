# Security Policy

UNIVERSAL is a document repository, not software, so its security surface
is small: the integrity of the text and the safety of anyone who interacts
with the project.

## Reporting a vulnerability

Please do not open a public issue for security problems.

- Use GitHub's private vulnerability reporting on this repository
  (Security tab, "Report a vulnerability")
- Or email: corey@slidphilabs.com with the subject line `UNIVERSAL security`

Include what you found, where, and how to reproduce it. You can expect
an acknowledgement within 3 business days. We will keep you updated while
we investigate and credit you unless you prefer to stay anonymous.

## In scope

- The integrity of the published document: tampered text, impersonated
  authorship, a pull request or commit smuggled in under a false identity
- Supply-chain issues in anything this repo publishes (badges, links,
  rendered pages)
- Privacy leaks in issues, pull requests, or discussions (exposed
  personal data, doxxing)

## Out of scope

- Social engineering, spam, or denial-of-service against the repository
- Claims about the philosophical content of the document itself
